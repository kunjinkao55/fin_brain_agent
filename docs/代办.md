## Phase 1.5：估值框架 + 回退鲁棒性（✅ 已完成，2026-07-23）

### 双锚点估值体系
- 主锚点：情景概率加权（机构标准多情景 DCF）
- 参考锚点：PE 乘数法（保守地板价）
- 结构突变检测：V 型反转时自动切换到年化 ROE + 最新季度数据
- 成长溢价扩展：B 级(≥5)→1.1, A 级(≥7)→1.3, S 级(≥9)→1.8

### 回退路径（3 轮 + ast 兜底）
1. 第 1 轮：完整 prompt + ANALYST_PROMPT → 原始 LLM → JSON 提取
2. 第 2 轮：精简 prompt（砍十步框架，只给数据+JSON 指令）
3. 第 3 轮：极简模板（字段模板 + 评分规则）
4. 兜底：`ast.literal_eval` 解析 Python 格式 dict
5. 空壳检测：AnalystOutput 全 null → 自动触发回退
6. 连接重试：`LLMFallbackChain` 对连接中断类错误 3 次退避重试

### 评分引擎时效修复
- 成长性：flash 提取容错（f_net==-100→回退季报对比）
- TTM EPS：跳过 flash 行 (`_快报源=True`)
- 结构突变：Q1 年化 ROE > 年报 ROE×2 → 自动覆盖
- 年化因子兜底：报告期字段未匹配时按日期月份推断
- 投资评级 ROE：同步使用结构突变修正后的 ROE

### 机构一致预期 ✅ 已完成

- 主数据源：同花顺 `stock_profit_forecast_ths()` 直抓（免费，结构化）
- 回退：Tavily Web Search（需 API key）
- 注入点：reporter 主流程顶层，不依赖 `_fix_and_decide`
- 渲染：`[机构共识]` 段落，含 EPS 一致预期 + 机构数 + 目标价（如有）
- 命中率：同花顺覆盖主流 A 股，免费且稳定

### API 响应速度优化 ✅ 已完成

- 概念板块排行：砍掉内层循环（原来 200+ 次 HTTP），加 1 小时缓存
- 龙虎榜：加 5 分钟缓存
- Web Search：SSL 容错 + 正则宽松匹配
- Few-shot 示例：`ANALYST_PROMPT` 新增完整单股 JSON 范例
- 双引号强制：4 处 prompt 显式标注 "双引号，禁止单引号"
- `[{...}]` 自动解包：接受数组包单对象格式
- Reporter 稀疏检测：有意义字段=0 → 视为解析失败

### 连接稳定性
- `LLMFallbackChain.invoke()` 对 `connection closed/reset/timeout/unexpected EOF` 类错误进行 3 次退避重试（3s/6s）

## Phase 1.7：报告系统三层结构性修复（✅ 已完成，2026-07-26）

> 依据：`docs/FinBrain报告系统_结构性问题与修复任务表.md`（托伦斯人工核验 18 项问题，自动审计检出率 ≈6% → 100%）
> 详细审计记录：`docs/技术审计与改进报告.md` 第二十轮

### 数据地基（L1/L2）
- 股本单一事实源 `share_registry.ShareContext`：reporter / calculate_scores / client.py 三路径统一 TTM 入口
- 公司行动事件分类器 `corporate_actions`：IPO/定增/配股/送转等 6 类，IPO 绝不落入定增分支
- 摊薄幂等：删除硬编码 0.874；仅定增/配股且 EPS 为变动前口径时允许调整
- BPS 口径配对：IPO 后含募集净额（披露值优先）；公式串显示=复算（A10）

### 计算与规则（L2/L3）
- 计算验证层 `calc_engine.CalcTable`：关键数字全部登记可回溯；隐含增速代码化覆盖 LLM 文本
- 涨跌停规则引擎 `trading_rules`：板块×上市天数×ST（新股前 5 日无限制不再误标"涨停"）
- 一致性不变量 `consistency`×6：区间锚定/SELL-买入价/情景对齐/禁用指标/全文唯一值/情绪-广度
- 指标生命周期注册表：前瞻 PE 禁用广播全部下游模块

### 次新股与闭环（L1/L3）
- 次新股数据包 `new_listing`：上市日期/解禁/流通盘/客户集中度/业绩预告（区间型解析）
- 业绩预告禁止回灌利润表；预告增速命中情景区间 → 强制标注"概率上升"
- 审计表 8 项 → 12 项守卫 + "已检查/未覆盖"清单，禁止裸报"0问题"
- 跨源比对：PE/PB/市值 双源偏差 >2% 告警

### 验证
- 托伦斯 golden 回归 26/26（18 项错误模式回放 18/18）+ e2e 72/72 + data_slots 17/17
- 真实数据冒烟（301583）：IPO 参数/TTM EPS 0.5159≈golden/流通盘 16.62% 全对

## Phase 1.9：可靠性加固 + 向高盛研报看齐 A 档（✅ 已完成，2026-07-26）

- 幻觉拦截三层：Critic 发现 grounding 过滤（硬数字必须可溯源原文）/ Repair 引入新数字即作废 / 股评转写"prompt 纪律→带违规清单重试→句子级剔除"三段防线

- 健壮性：情景逐情景补全（部分缺失不再裸退 PE 乘数法）、分析 JSON 解析围栏剥离（Python repr + ```json 双格式）
- 财报期次纪律：盈利能力/财务健康以最新期为主（季节性失真退回年报），FCF 恒走年报
- 报告期动态推算（expected_recent_periods）+ 头部覆盖标记

### 向高盛研报看齐 A 档（估值呈现层）
- 三锚点合理区间（PE乘数法/情景加权/SOTP）+ 情景 PE 行业中枢锚定带（跨轮方差 ±4x → 带内）
- 估值差距解读（PE 溢价/发行价涨幅/流通盘/隐含增速 vs 实际）+ 趋势参考买入价（近期支撑×1.05）
- A1 历史 PE band（近2年TTM PE 区间，次新股降级）/ A2 可比公司 PE/PB 对比（东财实时）/ A4 预期差三方对照（市场隐含 vs 机构一致 vs 本报告）
- A3 一致预期前瞻表（同花顺多年 EPS，无覆盖降级情景）/ A5 监测表（触发器/窗口/来源，取代观察指标段）

### 参数全配置化
- `configs/scoring.json [估值守卫]`：情景带/兜底模板/ROE乘数（接线闲置节）/成长溢价/乘数矩阵/SOTP/断路器/回溯容差/趋势参考/预期差阈值，零硬编码
